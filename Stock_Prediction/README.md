# Stock & Crypto Prediction App

This project predicts stock and cryptocurrency prices using Machine Learning (Random Forest) and Deep Learning (LSTM).  
It also includes a Streamlit web app for interactive predictions.

## Features
- Stock price prediction
- Crypto price prediction
- LSTM model
- Random Forest model
- Streamlit UI
- Data visualization

## Files in this project
- main.py
- streamlit_app.py
- stock_and_crypto_prediction.ipynb
- requirements.txt
